# Athkari — أذكاري

موقع أذكار الصباح والمساء، يشتغل كتطبيق على الجوال وبدون إنترنت.

## الرفع على GitHub Pages
1. أنشئ مستودع (Repository) جديد على github.com، واجعله Public.
2. ارفع كل محتويات هذا المجلد (كل الملفات، بدون مجلدات) بزر **Add file → Upload files**.
3. من **Settings → Pages**: اختر Branch: `main` والمجلد `/ (root)` ثم Save.
4. بعد دقيقة أو اثنتين يظهر الرابط: `https://اسمك.github.io/اسم-المستودع/`

## إضافته للشاشة الرئيسية
- **أندرويد (Chrome):** افتح الرابط ← القائمة ⋮ ← **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.
- **آيفون (Safari):** زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.

بعد أول فتح بالنت يشتغل بدون نت. وإذا عدّلت الملفات يتحدث التطبيق عند الفتح مرتين.
